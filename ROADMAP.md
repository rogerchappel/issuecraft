# Roadmap

## 0.1 MVP

- Offline log-to-draft workflow.
- TODO/FIXME scanning workflow.
- Markdown drafts with provenance and fingerprints.
- GitHub CLI preview command generation.
- Fixture-backed tests and smoke validation.

## Next

- Configurable draft templates.
- Git status evidence summaries.
- Duplicate grouping across an issue draft folder.
- JSON output for agent pipelines.
- Interactive review mode for accepting or rejecting drafts.

## Later

- Explicit, confirmation-heavy GitHub posting mode.
- Editor integrations.
- Release-manager bundles for milestone triage.
